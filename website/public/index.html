GitTrellis is an opinionated desktop client for reviewing diffs, staging individual hunks, and following the history of your branches.

Get the Fedora RPM Fedora 45 x86_64 · Alpha

From diff to commit

Stage by hunk
Review unified or side-by-side diffs and choose which hunks go into the next commit.
Read the commit graph
Follow branches and merges, then inspect the changes behind a commit.
Keep your Git setup
Use your existing SSH agent, credential helpers, and commit signing.

Install on Fedora

Download the alpha RPM for Fedora 45 x86_64 from GitHub Releases. Run this command from your download directory.

Browse releases 
sudo dnf install ./gittrellis-*.fc45.x86_64.rpm
